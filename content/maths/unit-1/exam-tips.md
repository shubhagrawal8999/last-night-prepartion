# How to Write It in the Exam

- **Write the rule first.** Name the power, product, or chain rule before using it.
- **Show one step per line.** The marker can award method marks even if arithmetic goes sideways.
- **Keep notation clear.** Write $\frac{dy}{dx}$ or $f'(x)$ consistently.
- **Check constants.** A standalone constant differentiates to zero.
- **For a graph question,** label axes and the point where you found the gradient.

### Common slips

- Forgetting to reduce the exponent after bringing it down.
- Dropping a coefficient when differentiating a term.
- Applying the power rule to a product without using the product rule.

> Demo advice only. Your instructor's marking scheme wins any tie.
